你好，我是 NEST 的作者。这是一款从我自己的使用需求出发做的 Windows 桌面笔记软件。

最初，我想要的其实就是一个顺手的小便签。工作时可以放在旁边，随时写两笔，也能置顶；不需要的时候，最好能让我忘记它还在那里。

但我又不想它真的只能当便签。有些记录写着写着，就会变成一个需要反复补充的主题。我希望能顺着原来的内容继续往下写，而不是到了这一步，又得另建目录、把内容搬去别的地方。

所以，NEST 做成了现在这样：**双击进入一条记录，就能在里面继续添加条目；需要整理和查找时，再把相应的工具展开。**

## 先写一条，后面想到什么再往里加

比如你准备做一个个人网站。点击底栏 `＋`，或者按 `Ctrl+N`，写下“做一个个人网站”就行了。

有了更多想法，双击这条记录，进去添加“首页草图”“参考页面”“发布第一版”。“发布第一版”下面还需要测试、检查链接？再双击进去，接着写。

</p>

<p align="center"><sub>双击进入下一层，用后退回到刚才的位置。小窗口一次只显示当前这一层。</sub></p>

NEST 把每条记录叫作**条目**。它可以是一句话、一段笔记，也可以是一件待办；不管写成什么样，都能继续包含下一层条目，不用另外转换成“笔记本”或“项目”。

这里的结构也不是软件自动替你分好的。你想往哪里继续写，就进入哪里；以后觉得放得不合适，还可以再移动。

**单击改这一条，双击进入它。** 日常操作主要就是这些：

| 想做什么 | 怎么操作 |
| --- | --- |
| 新建一条 | 点击底栏 `＋`，或按 `Ctrl+N` |
| 修改内容 | 在笔记区单击条目 |
| 完成编辑 | 默认按 `Enter`；`Shift+Enter` 换行，`Ctrl+Enter` 始终完成 |
| 进入下一层 | 双击未编辑的条目，或点击行末进入图标 |
| 回到刚才的位置 | 点击后退图标 |

正在编辑文字时，双击仍然用于选词，不会突然把你带进下一层。快捷键和 Enter 的用法可以在设置中调整。

条目支持 Markdown，加粗、待办、引用和代码都可以直接写。一条待办下面可以放执行步骤，一段阅读记录下面也可以继续放摘录和自己的想法。

## 内容多了，再把结构展开

平时，一个小窗口就可以新建、编辑、逐层进入。把它置顶，还能放在浏览器或工作软件旁边，不用来回寻找。

如果只看当前这一层不够了，打开底栏的**结构**面板，就能看到更完整的目录，在里面展开层级、调整顺序、移动条目。内容仍然在笔记区编辑。

## 忘了放在哪，搜一下

记得写过什么，却想不起放在哪一层，可以直接打开**搜索**，输入记得的文字。

结果里会显示所在路径。单击结果可以定位并高亮，双击就能进入对应条目，不用先从目录里一层层找。

## 正在忙别的，也能顺手记一件事

还有一个**收集**面板，用来处理“不想离开现在的位置，但又有东西想记下来”的时候。

打开收集，输入内容，保存到收集箱、当前条目，或者另选一个位置。还没想好归属，就先放进收集箱，之后再决定要不要整理。

## 下载试试

在 [Releases](https://github.com/Kiteyui/NEST/releases) 下载，具体版本情况和已知问题以对应发布说明为准。目前提供 Windows x64 版本：

| 类型 | 怎么选 |
| --- | --- |
| 轻量安装版 | 下载体积较小；电脑缺少 WebView2 运行时的话，安装时需要联网下载 |
| 完整安装版 | 自带 WebView2 离线安装组件，适合安装时不方便联网的电脑 |
| 便携版 ZIP | 完整解压后直接运行，需要电脑已经安装 WebView2 运行时 |

第一次打开，选择一个文件夹、给空间起个名字，就可以开始了。已有空间也可以直接打开。

<p align="center">
  <img src="assets/readme-20261024/start.png" width="423" alt="实机截图：NEST 首次进入界面，可创建空间或打开已有空间" />
</p>

进入后，点击底栏 `＋` 写下第一条。不同用途可以分成不同空间，在同一窗口切换，不需要一次把它们都安排好。

便携版请先解压，不要在压缩包里运行。下载的软件也不要解压到自己的笔记数据库文件夹里。

更多操作、空间切换和升级方法，放在 [使用指南](docs/usage.md) 中。

## 笔记存在哪里？怎么备份？

NEST 不需要账户。正文、层级和空间状态，都保存在你创建空间时选择的文件夹里。

不过有件事需要说清楚：**支持 Markdown，不等于每条笔记都保存成了一个 `.md` 文件。** NEST 目前使用 SQLite 数据库，不能像普通 Markdown 文件夹那样，直接用其他文本编辑器修改里面的笔记。

网页标题读取默认关闭。只有你开启这项设置，NEST 才会请求输入的网页地址、读取标题；这项功能需要联网。

**备份时，先彻底退出 NEST，再复制整个空间文件夹。** 关闭窗口可能只是隐藏到托盘，不等于程序已经退出。升级前也请备份，不要让旧版本直接打开新版数据库。详细步骤见 [保存与备份](docs/usage.md#保存与备份)。

## 我为什么想把它做好

NEST 是个人项目，很多取舍都来自我自己对工具的偏好：能简单一点就简单一点，但不要因为界面小，就只能做很少的事。

我很喜欢这样的过程：最初随手记了一句话，后来又补了一点，慢慢发现它值得继续做下去。回头再看，里面已经有了自己的思路和安排。这也是“让结构在记录中生长”想表达的意思。

当然，不是每条记录都要成为一个项目。拿它记几件今天要做的事，也很好。

我希望 NEST 是一个让人愿意拿起来用的东西，而不只是一个功能列表看起来很完整的软件。这个区别对我很重要。

## 欢迎来用，也欢迎直接告诉我哪里不好用

我的习惯未必和你一样，所以我也很想知道，NEST 放进你的工作里会是什么样。

哪里让你多点了一次，哪句话没看懂，哪个操作和你预想的不一样，都可以告诉我。不用先整理成一份专业评审，说清楚“我想做什么，点了哪里，结果发生了什么”就已经很有帮助。

用得顺手的地方也欢迎说说。知道哪些值得保留，和知道哪里需要改一样重要。

反馈可以发到 [Issues](https://github.com/Kiteyui/NEST/issues)。如果是具体问题，麻烦附上 NEST 版本、Windows 版本、缩放比例和复现步骤。截图请遮盖私人内容和路径，**不用上传笔记数据库**。

谢谢你愿意试试我做的东西。希望它能在某个时候，刚好帮上你的忙。
