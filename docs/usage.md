# 使用指南

## 第一次打开

1. 从本项目 Release 下载安装版，或将便携版解压到有写入权限的文件夹
2. 启动 NEST，选择保存空间的文件夹，输入空间名称
3. 使用底栏 `＋` 创建第一条笔记；默认快捷键为 `Ctrl+N`，以设置页为准

在线安装版会检查 Microsoft Edge WebView2 Runtime，缺少时联网下载并安装；无法联网时请选包含离线组件的安装版。便携版需要系统已安装 WebView2，也可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装

## 日常操作

| 操作 | 方法 |
| --- | --- |
| 编辑条目 | 单击内容 |
| 进入条目 | 在未编辑条目上双击，或点击行末进入图标 |
| 回到空间最上层 | 点击导航区主页图标 |
| 返回刚才的位置 | 点击后退图标 |
| 完成编辑 | 默认 Enter，Ctrl+Enter 始终完成；Shift+Enter 换行 |
| 查找内容 | 底栏搜索，默认 Ctrl+K |
| 整理层级 | 底栏结构，默认 Ctrl+E |
| 收集想法 | 底栏收集，默认 Ctrl+J |
| 新建或切换空间 | 更多 → 设置 → 空间中的空间管理入口 |

快捷键和 Enter 行为可在设置中调整。输入法正在选择候选词时，Enter 用于确认输入

## 保存与备份

- `nest.sqlite` 保存正文、层级和空间状态；运行时可能同时存在 `nest.sqlite-wal`、`nest.sqlite-shm`
- 所选空间内的 `.nest-app` 用于本地运行状态
- 程序旁的 `nest-storage.json` 和 `nest-spaces.json` 记录空间位置，不要把这些文件作为软件的一部分分享
- 备份前从托盘或应用入口彻底退出 NEST，再复制整个空间文件夹。关闭窗口可能只是收起到托盘
- 更新程序前先备份。恢复旧版本之前，应使用与该版本兼容的备份，不要让旧程序直接打开新版数据库

选择位置失败时，确认文件夹存在并有写入权限，再重新选择。程序不会把你的笔记悄悄改存到另一个默认位置

## 升级

退出 NEST 后安装新版，或将便携版解压到新的文件夹。首次打开新位置的程序时，可选择原空间文件夹继续使用。不要用下载包覆盖自己的数据库，也不要将发布包解压到笔记数据库内部
